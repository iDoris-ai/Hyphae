# 生态里程碑草案

默认中文沟通。整体编号 E-M1～E-M5，保留 Hyphae 历史编号。

## 架构边界

- Agent24：执行、审批、记忆、调度；加载能力模块、领域 OS 和外部 workspace。
- AgentEar：听说、设备权限，支持嵌入及独立运行。
- iDoris：本地/API 模型、推理意图路由、隐私、预算及用量。
- Hyphae：核心网络：身份、发现、加密通信、行为及协作协议；执行交给 Agent24。

## 大里程碑

1. **E-M1：最小协作闭环。** 单 relay、双 Agent 跑通发现到回执，接通语音、模型与外部模块。承接历史 M2。
2. **E-M2：网络扩展。** 自部署、多 relay 接力、TTL/去重、漂流瓶、资料分级披露。承接旧 M1.5/M2.5。
3. **E-M3：任务协作。** 协商、委派、取消、验收；Agent24 执行和审批，Hyphae 同步跨节点状态。承接旧 M3。
4. **E-M4：长期自治。** 订阅、匹配、恢复、调度和活动记录；验证长跑及防消息循环。承接旧 M4。
5. **E-M5：价值交换。** 授权、信誉、AAstar Point 支付及对账，先验收测试网。承接旧 M2.5/M5。

## E-M1 拆分与出口

- **1. 契约：** 固定身份、能力、版本、请求/回执关联及授权范围；兼容现有桥接和旧事件。
- **2. 可靠通信：** 修复 SQLite 连接配置、outbox 并发、密文明文覆盖；实现 register/publish/inquire/subscribe 信封。
- **3. 模型：** 接入 iDoris，验证预算、隐私及实际落点；本地不可用不得绕到外部。
- **4. 模块：** 复用 AgentEar 附着协议；用真实外部 OS/workspace 验证加载、权限、生命周期及结果承载。
- **5. 联通：** 更新 Hyphae 桥接，授权后单步执行和回执；持久化去重，重启不重复执行。
- **6. 联合验收：** 单元、真实 relay、四仓联调三道门；验证语音请求→远端执行→结果播报，以及断线、重启、拒绝路径。

顺序：1→2/3/4 并行→5→6。M1 不含跨 relay、自动协商、支付、联邦训练、完整 workspace 产品。
