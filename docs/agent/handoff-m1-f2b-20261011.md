**LoopX 状态: 已 `stop`（操作员要求不再自动唤醒）**，可用 `goal-lifecycle --operation resume` 恢复。

恢复自动续跑：
```sh
# LoopX 层
loopx goal-lifecycle --goal-id hyphae-m1-release-goal --operation resume --actor-kind controller --execute
# Pi 层（在 Pi 会话里）
/loopx resume
#   或
/loopx --goal-id hyphae-m1-release-goal --agent-id pi-hyphae-m1-controller 完成M1发布门，续用现有Todo，文档合并不算实现完成
```
**坑 1**: Pi 的 LoopX 循环**遇到人工消息会自动暂停**（`autoResume=false`）——恢复后**不要再发消息**，否则立刻又暂停。
**坑 2**: `/loopx resume` 只置标志、不触发 turn；循环要靠一次 “agent turn settle” 才会重排 3 分钟定时器。

心跳标准操作（每个 turn）：
```sh
LOOPX_TURN=$(date -u +%Y-%m-%dT%H:%M:%SZ)
loopx --format json --registry "$HOME/.codex/loopx/registry.global.json" quota should-run \
  --goal-id hyphae-m1-release-goal --agent-id pi-hyphae-m1-controller \
  --available-capability task_lease_v0 --runtime-profile generic_cli --turn-instance-id "${LOOPX_TURN:?}"
# 有证据的推进后（refresh 与 spend 必须同 turn-instance-id；spend 要在 refresh 记录的 delivery workspace 内执行）
loopx --format json refresh-state --goal-id hyphae-m1-release-goal --classification <...> \
  --delivery-batch-scale single_surface --delivery-outcome outcome_progress --delivery-boundary in_flight_continuation \
  --delivery-workspace-path <delivery worktree> --todo-id <todo> --turn-instance-id "$LOOPX_TURN" \
  --agent-id pi-hyphae-m1-controller --available-capability task_lease_v0
loopx --format json quota spend-slot --goal-id hyphae-m1-release-goal --slots 1 --source heartbeat --execute \
  --todo-id <todo> --turn-instance-id "$LOOPX_TURN" --agent-id pi-hyphae-m1-controller --available-capability task_lease_v0
```
**坑 3**: `refresh` 与 `spend` 的 `--turn-instance-id` 不一致 → `unsettled_host_turn_recovery`；`spend` 不在 delivery workspace 内 → `quota spend workspace does not match`。
**坑 4**: `todo add --task-repository` 传**已编码**值会二次编码（`git:git%2Fgit%2F...`）导致 `refresh-state` 报 `task_repository must identify a Git repository`；应传 `git:github.com/iDoris-ai/Hyphae`。

**硬闸门（不可越过）**：只合并“**精确 head 的 clestons(external PR-Daemon) APPROVE + required CI 全绿 + mergeable**”三者同时满足的 PR；**任何人不得自行批准**；**不得修改已批准 PR 的 head**；发布/打 tag/生产操作需操作员显式授权；private 证据/凭据不入提交。
