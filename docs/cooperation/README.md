# 跨仓协作清单

更新：2026-09-29。每份文档按对方仓库命名，供负责人推动实施。状态为“Hyphae 侧提出，待对仓确认”；不表示对方已经承诺、实现或通过验收。本轮不修改这些仓库，也不代发协作消息。

| 仓库 | 协作重点 | 对基础 CLI 通信的依赖 |
|---|---|---|
| [Agent24](Agent24.md) | 统一 CLI 入口、基础通信 UI、打包与兼容验证 | 统一产品入口需要接线；Hyphae 可独立使用 |
| [AgentEar](AgentEar.md) | 语音进入既有通信通道，复用附着权限与播报 | 不阻塞文本通信 |
| [iDoris](iDoris.md) | 模型路由、隐私、用量与推理落点 | 不阻塞消息传输 |
| [Sin90](Sin90.md) | 真实外部 OS 加载/停用与获授权的单步只读查询样例 | 不阻塞基础 CLI；用于 T12/T13 高层闭环 |
| [nostrlib 上游](nostrlib.md) | 固定 NIP-44 实现的 MAC 常数时间比较及升级验收 | 现有通信版本不变；符合性差异单独收口 |
| [relay-khatru（拟议）](relay-khatru.md) | relay 部署、邀请与私有策略、上游适配归属 | 独立仓库的建立不阻塞基础 relay 迁移 |

各仓确认时应补：负责人/PR、选定的 Hyphae commit 或版本、接口差异、实际验收命令与结果。发现不兼容时先修改接口约定，再开发；未知状态保留为待确认。

共同边界：Hyphae 管网络传输和身份；Agent24 管执行和审批；AgentEar 管设备和语音；iDoris 管模型路由及其约束。普通消息、relay 连接权限与执行授权分别管理。
